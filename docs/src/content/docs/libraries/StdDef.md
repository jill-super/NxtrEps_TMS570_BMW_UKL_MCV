## Purpose and responsibility

Project-wide standard types and compiler/platform abstractions (AUTOSAR standard types, compiler and platform type headers, device register definitions).

## Directory layout

Sources live in `StdDef/`. The standard module layout is:

| Folder | Content |
| --- | --- |
| `src/` | — — C/assembler implementation and local headers |
| `include/` | present — Public headers (if present) |
| `generate/` | — — Generator batch files / templates (if present) |
| `tools/` | — — Host-side helper scripts (if present) |
| `utp/` | — — Unit-test project artefacts (if present) |

## Usage notes

The `StdDef` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
