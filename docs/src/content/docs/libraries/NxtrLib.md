## Purpose and responsibility

Shared in-house library: fixed-point math, filters, interpolation, trigonometry, checksums and system-time helpers used by all layers.

## Usage notes

The `NxtrLib` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
