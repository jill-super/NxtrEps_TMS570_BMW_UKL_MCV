## Purpose and responsibility

Central application diagnostic manager: collects faults from all components, debounces them, triggers fail-safe actions and interfaces to the AUTOSAR Diagnostic Event Manager.

## Usage notes

The `DiagMgr` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
