## Purpose and responsibility

Safety timing monitor: generates the watchdog-monitor signal edges at the start of the fast task and checks program-flow timing.

## Usage notes

The `TmprlMon` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
