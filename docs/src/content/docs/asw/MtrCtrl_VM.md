## Purpose and responsibility

Voltage-mode motor control package: current estimation, parameter compensation, phase control, quadrature detection, torque-command scaling and voltage control. Variant designation (VM) is documented as an assumption (see Glossary).

## Usage notes

The `MtrCtrl_VM` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
