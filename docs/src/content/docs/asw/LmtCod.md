## Purpose and responsibility

Variant-coding of torque and effort limiters so limits match the coded vehicle/market configuration.

## Usage notes

The `LmtCod` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
