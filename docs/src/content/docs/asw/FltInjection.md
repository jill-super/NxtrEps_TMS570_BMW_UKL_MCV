## Purpose and responsibility

Test-only component that injects faults at defined locations to validate diagnostics and safety mechanisms. Excluded from production builds.

## Usage notes

The `FltInjection` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
