## Purpose and responsibility

Compensates dynamic instabilities (for example driveline or chassis interactions) in the steering control loop.

## Usage notes

The `StabilityComp` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
