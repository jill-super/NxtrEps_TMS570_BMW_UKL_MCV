## Purpose and responsibility

Supervises the electrical power budget of the steering system and coordinates load reduction with the vehicle power supply.

## Usage notes

The `ElecPwr` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
