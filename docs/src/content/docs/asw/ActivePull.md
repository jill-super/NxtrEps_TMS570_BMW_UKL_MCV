## Purpose and responsibility

Compensates vehicle pull/drift by adding a corrective torque overlay so the vehicle tracks straight on crowned or uneven roads.

## Usage notes

The `ActivePull` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
