## Purpose and responsibility

Central mode manager: owns the Electric Power Steering system-state machine and publishes the state mode used by all components.

## Usage notes

The `StaMd` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
