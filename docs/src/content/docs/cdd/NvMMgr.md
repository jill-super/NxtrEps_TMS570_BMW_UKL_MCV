## Purpose and responsibility

Complex device driver wrapping the Flash EEPROM Emulation: owns block management, write prioritisation and error recovery for non-volatile data.

## Usage notes

The `NvMMgr` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
