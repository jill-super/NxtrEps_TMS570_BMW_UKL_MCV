## Purpose and responsibility

Microcontroller-level diagnostics for the TMS570: abort handling, clock monitoring, Error Correction Code monitoring, Error Signaling Module supervision, floating-point checks, input-output memory management and loss-of-execution detection.

## Usage notes

The `TMS570_uDiag` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
