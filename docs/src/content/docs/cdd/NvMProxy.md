## Purpose and responsibility

Proxy that routes application non-volatile requests to the memory manager, decoupling software components from the memory stack.

## Usage notes

The `NvMProxy` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
