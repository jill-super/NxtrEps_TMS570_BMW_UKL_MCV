## Purpose and responsibility

Shared diagnostic-service implementation used by all variants, including the Unified Diagnostic Services and Universal Measurement and Calibration Protocol service tables.

## Usage notes

The `CMS_Common` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
