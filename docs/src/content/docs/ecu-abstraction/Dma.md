## Purpose and responsibility

In-house Direct Memory Access driver that offloads bulk data movement (for example Analog-to-Digital Converter results) from the central processing unit.

## Usage notes

The `Dma` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
