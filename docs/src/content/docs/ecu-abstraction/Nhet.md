## Purpose and responsibility

In-house driver for the New High-End Timer co-processor, including the timer programs for motor control and signal capture.

## Usage notes

The `Nhet` component is scheduled through the Runtime Environment: periodic runnables run in their assigned operating-system task/rate, initialisation runnables run during startup, and client-server (`Scom`) operations are invoked by testers, manufacturing services or other components. Calibration constants are tuned via the measurement and calibration tool chain (see [Tools and Build System](../tools/)).
