Every module page in this documentation carries an **origin badge**. This page explains what the badges mean and the rules that follow from them.

## The three origins

### Custom — in-house implementation

Developed in-house (Nexteer) for this Electric Power Steering project. This covers:

- All Application Software components (`Ap_*`, `Sa_*`) — the control behaviour is owned by this project even though the file skeleton was generated by the Vector MICROSAR Runtime Environment generator.
- In-house drivers and services: `Adc/`, `Dma/`, `Nhet/`, `SpiNxt/`, `DiagMgr/`, `StaMd/`, `NvMMgr/`, `TMS570_Startup/`, `TMS570_uDiag/`, `NxtrLib/`, `StdDef/`, and similar.
- **BMW customer-specific** variants (`BmwHaptcFb/`, `BmwTqOvrlCdng/`, `CBD_BmwRtnAbrn/`, `CustPL_BMW/`, `ParkAstEnbl_BMW/`, `CMS_BMW/`) — additionally bound by BMW vehicle-interface agreements.

**Rule:** safe to modify following the project's change process (version log in the file header, unit tests in `utp/`, quality-gate checks).

### Vector-provided — third-party MICROSAR code

Provided by Vector Informatik as part of MICROSAR, or generated by Vector tools (DaVinci Configurator, MICROSAR Runtime Environment generator, Basic Software generators). This covers:

- The communication and system stack: `BSW/Com`, `BSW/ComM`, `BSW/PduR`, `BSW/Fr*`, `BSW/EcuM`, `BSW/NvM`, `BSW/MemIf`, `BSW/WdgM`, `BSW/Dcm`, `BSW/Os`, `BSW/Mcu`, `BSW/Port`, `BSW/Dio`, `BSW/Gpt`, `BSW/Spi`, and similar.
- All generated artefacts: `Source/GenData/`, `Source/GenDataRte/`, `Source/GenDataOS/`, `Source/GenDataE2EPW/`.
- Top-level `FrTrcvPhy/` (MICROSAR FlexRay Transceiver Driver).

**Rule:** do not edit manually — change the DaVinci configuration and regenerate, or take a new Vector delivery.

### Third-party code (other vendors)

- **Elektrobit:** `BSW/Dem` (Diagnostic Event Manager implementation).
- **Texas Instruments:** `Fee/` (Flash EEPROM Emulation), `Fls/` (F021 flash programming interface), `Tools/nowECC/`.
- **Gliwa:** `GliwaT1/` (T1 timing-measurement library).
- **Open source:** `BSW/Nrv2b` (NRV2B decompression).

**Rule:** update only via official vendor deliveries; never fork the code.

## How origins were determined

Origins were assigned by inspecting, for each module, the copyright and generator banners in the source headers:

- `Copyright … Vector Informatik GmbH` / `MICROSAR` / `DaVinci` / `GenData` → Vector-provided.
- `Copyright … Elektrobit / Texas Instruments / Gliwa` → third-party.
- `Copyright … Nexteer` or a `MICROSAR Runtime Environment generator` template banner with in-house control code → custom in-house.
- BMW-specific component names and customer diagnostic services → custom, BMW customer-specific.

Where a name expansion or assignment is uncertain, the page says so explicitly and the [Glossary](./glossary/) records the assumption.
